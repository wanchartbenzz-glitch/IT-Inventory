## What's Working

1. **Traceability เป็นวัตถุชั้นหนึ่งใน UI** — `lotPickerHtml` → `serialPickerHtml` → `cartSummaryRows` → `showReceipt` พาล็อต→PO→Serial จากตัวเลือกถึงใบเสร็จโดยไม่พิมพ์ซ้ำ จุดประสงค์ข้อ 2 บรรลุบนเดสก์ท็อป
2. **ข้อความ validation อธิบายเหตุผลทางธุรกิจ** — "ระบุผู้จำหน่าย — คือคนที่ต้องส่งเคลมไปหา" สอนโมเดลให้เด็กใหม่โดยไม่ต้องมีคู่มือ
3. **Blind count ซื่อสัตย์ตั้งแต่ต้นจนจบ** — ไม่มีทางลัด, เผยยอดต่อแถว, กันปิดหน้า, กู้คืนพร้อมเวลา, ไดอะล็อกแยก "ไม่ได้นับ" จาก "ตรงกัน" (B ยืนยันด้วยการวัด: ซ่อนก่อนพิมพ์ → เผยหลังพิมพ์ → รีโหลดแล้วค่ากลับมา)
