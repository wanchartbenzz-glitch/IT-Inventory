## Minor Observations

- Sidebar เดสก์ท็อปสูง 900: "IT Assets Coming Soon" ถูกตัด และปุ่มย่อเมนูอยู่ y=923 นอกจอ
- รับเข้า: แถวแรกถูกเลือกอัตโนมัติ กด "ถัดไป" โดยไม่อ่านได้ Wireless Mouse; ชื่อขั้น "ระบุจำนวน" มี 10 ช่อง 3 ส่วน; ลำดับช่องควรเป็น PO → ผู้จำหน่าย → ประกัน ก่อน
- เบิก: `#reqName` เติม "สมชาย ใจดี" ขณะ header บอกว่าเป็น "IT Support"
- คืน: ปุ่ม "ยกเลิก" เห็นก่อนเลือกอะไร ส่วนปุ่มยืนยันซ่อน — การกระทำเดียวที่เห็นคือออก; คลิกรายการกับช่องค้นหาทำงานซ้ำกัน
- เคลมที่ปิดแล้วยังโชว์ "อยู่ในประกันถึง…" สีเขียว ควรเป็น "ปิดเรื่อง 12 ก.ย. 2569"
- อนุมัติ: แสดง "คงเหลือ" แต่ไม่แสดง "จะเหลือหลังอนุมัติ" ซึ่งคือเลขที่ใช้ตัดสินใจ
- ประวัตินับ: "IT Support" คนเดียวทั้งนับและอนุมัติ ADJ ไม่มีร่องรอยการแยกบทบาท
- ปุ่ม `.btn-primary` ที่ disabled เพี้ยนเป็น Bootstrap #0d6efd (ไม่ได้ override `--bs-btn-disabled-bg`)
- inline hex 31 จุดใน HTML/JS เพราะ palette ไม่มีโทเคน *-border / *-text-dark
- `font-family: "Inter"` เปล่าไม่มี fallback 6 กฎ — ฟอนต์โหลดไม่ได้จะตกไป UA default ไม่ใช่ Noto
- หัวข้ออังกฤษบน Dashboard ("Stock Health", "Create Issue" — Issue กำกวม ticket vs เบิก) ใน UI ไทย
- ไม่มี favicon; แนวนอนบนมือถือ `.cart-summary-bar` 72px ทับบรรทัดสถานะการ์ดสุดท้ายในหน้านับ
- ข้อมูลตัวอย่าง 10 รายการ ไม่เคยทดสอบเคส "128 SKU จริง" — picker 320px และหน้านับจะต้องมีการจัดกลุ่ม/virtualize ที่ยังไม่ได้ออกแบบ
