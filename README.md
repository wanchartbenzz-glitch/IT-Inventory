# IT Inventory

ระบบจัดการสต๊อกอุปกรณ์ IT — **front-end เท่านั้น** (HTML + Bootstrap 5.3 + jQuery) ออกแบบให้นำไปต่อกับระบบหลังบ้านและ login ที่มีอยู่แล้ว
ทุกปุ่ม "บันทึก/ยืนยัน" ทำงานกับข้อมูลตัวอย่างในหน้าเว็บเท่านั้น ไม่มีการเรียก API ใด ๆ

## จุดประสงค์ของระบบ

1. **รู้ว่าอุปกรณ์แต่ละชิ้นถูกนำไปใช้ที่ไหน** — `item.deployments[]` (เบิกถาวร / ยืม)
2. **ย้อนกลับได้ว่าของชิ้นนี้มาจาก PO ไหน** เพื่อส่งเคลม — `item.lots[]` (PO, ผู้จำหน่าย, ราคา, วันหมดประกัน, Serial)

## หน้าทั้งหมด

| หน้า | ไฟล์ | ทำอะไร |
|---|---|---|
| Dashboard | `index.html` | KPI, สุขภาพสต๊อก, แผง **ต้องดำเนินการ** (ยืมเลยกำหนด / รออนุมัติ / เคลมค้าง) |
| รับเข้าอุปกรณ์ | `receive.html` | เลือกของ → จำนวน + แปลงหน่วย (1 กล่อง = 305 เมตร) → บังคับ PO, ราคา, วันหมดประกัน, Serial รายชิ้น |
| เบิกอุปกรณ์ | `issue.html` | ตัดสต๊อกถาวร · เลือกล็อต (FIFO) · เลือก Serial · ระบุสถานที่ใช้งาน |
| ยืมอุปกรณ์ | `borrow.html` | เหมือนเบิกแต่มีกำหนดคืน |
| คืนอุปกรณ์ | `return.html` | รายการยืมค้าง เรียงตามความเร่งด่วน + ป้ายเลยกำหนด |
| ส่งซ่อม / ตัดจำหน่าย | `service.html` | บันทึกของที่ส่งซ่อม ชำรุด ตัดจำหน่าย (เตือนถ้ายังอยู่ในประกัน) |
| ตรวจนับสต๊อก | `stock-count.html` | นับประจำเดือน คำนวณผลต่างสด ส่งผลต่างเข้ารออนุมัติ + ประวัติย้อนหลัง |
| รออนุมัติ | `approvals.html` | คำขอเบิก/ยืม/ปรับยอด/ตัดจำหน่าย อนุมัติหรือไม่อนุมัติ (ต้องระบุเหตุผล) |
| ประวัติการเคลม | `claims.html` | เปิดเคลมอ้าง PO/ล็อต/Serial ตรวจสถานะประกันก่อนส่ง |
| ข้อมูลอุปกรณ์ | `inventory.html` / `inventory-detail.html` | รายการ + รายละเอียด (ถูกใช้ที่ไหน, ล็อต & PO, Serial, ส่งซ่อม/เคลม) |
| หมวด / ประเภท / หน่วยนับ | `categories.html` `types.html` `units.html` | ข้อมูลหลัก |

ช่องค้นหาด้านบนพิมพ์ชื่อ / รหัส / **Serial** แล้วกด Enter → ไปหน้ารายการอุปกรณ์พร้อมกรอง
ทุกหน้ารายการมีปุ่ม **ส่งออก CSV** (สร้างในเบราว์เซอร์ มี BOM เปิดใน Excel ภาษาไทยได้)

## โครงสร้าง

```
js/data.js      ข้อมูลตัวอย่างและ helper ทั้งหมด (single source of truth)
js/cart.js      ตะกร้าเบิก/ยืมที่ใช้ร่วมกัน (ล็อต + Serial)
js/shell.js     พฤติกรรม sidebar/header + การแจ้งเตือนจากข้อมูลจริง + ค้นหา
js/app.js       helper ทั่วไป (toast, ปุ่มโหลด, closeModal)
css/app.css     design system ทั้งหมด
partials/       header ที่ใช้ร่วมกัน
build.js        ฝัง sidebar/header ลงทุกหน้า
assets/items/   รูปอุปกรณ์ (ดู README ในโฟลเดอร์)
```

หลังแก้เมนูใน `build.js` หรือ `partials/header.html` ให้รัน

```
node build.js
```

## กฎของข้อมูลใน `data.js`

- `sum(item.lots[].remaining) === item.stock` เสมอ — ล็อตที่ยังมีของคือสิ่งที่ตัวเลือกล็อตแสดง
- อุปกรณ์ที่ `serialized: true` เก็บ Serial ที่ `lot.serials[]` (ยังอยู่ในสต๊อก) และ `deployment.serials[]` (จ่ายออกแล้ว)
- วันที่เป็น พ.ศ. รูปแบบ `13 ก.ย. 2569` — ใช้ `parseThaiDate()` / `formatThaiDate()`

## การต่อกับระบบจริง

จุดที่ต้องเปลี่ยนคือ `js/data.js` (แทนที่ array ด้วยข้อมูลจากระบบ) และ handler ปุ่มบันทึกในแต่ละหน้า (ตอนนี้แค่แสดง toast)
**ห้าม** ฝัง API key / รหัสผ่าน / connection string ลงในไฟล์ฝั่งหน้าเว็บ
