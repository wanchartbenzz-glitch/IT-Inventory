# รูปภาพอุปกรณ์ (Item photos)

วางไฟล์รูปของอุปกรณ์ในโฟลเดอร์นี้ โดยตั้งชื่อไฟล์ตามรหัสอุปกรณ์ เช่น:

    IT-MOU-001.jpg
    IT-KEY-001.jpg
    IT-SSD-001.jpg

แล้วไปกำหนดค่า `image` ของอุปกรณ์นั้นใน `js/data.js`:

    image: 'assets/items/IT-MOU-001.jpg'

ถ้ายังไม่มีรูป ให้ปล่อยเป็น `image: null` ระบบจะแสดงไอคอนประจำหมวดแทนโดยอัตโนมัติ
และถ้าไฟล์รูปหาไม่เจอ (ลิงก์เสีย) ระบบจะ fallback กลับไปใช้ไอคอนให้เอง

ขนาดรูปที่แนะนำ: สี่เหลี่ยมจัตุรัส อย่างน้อย 200x200px (แสดงผลแบบ object-fit: cover)
